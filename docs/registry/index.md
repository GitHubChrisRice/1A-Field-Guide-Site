# Facility Registry

<div class="registry-hero" markdown>

**California Active · Contra Costa Researching.** These four pilot facilities were rerun against the qualified California overlay on September 30, 2026. The Registry separates **forum classification**, **confidence**, **recording posture**, and **field verification** so a pending site visit does not make an otherwise answerable legal question look unresolved.

Forum labels below are **project classifications**, not claims that a court has adjudicated that exact address.

## What changed from the first preview

The Registry no longer labels an entire facility “unresolved” because one room, sign, boundary, or state-law question is open.

The hardening pass uses this rule:

> **Classify now when the missing field fact cannot reasonably change the result. Keep only outcome-determinative uncertainty unresolved.**

That means a municipal sidewalk can be **TPF / HIGH** even if the survey-grade edge has not been staked in the field; a DMV or police lobby can be **NPF / HIGH federally** even though no case has litigated that exact address; and a library interior can be **LPF / HIGH for library-purpose activity** while the separate question of patron filming remains narrower and activity-specific.

See the [classification method](method.md) and [four-pilot hardening record](../research/REGISTRY-CLASSIFICATION-HARDENING-2026-09-23.md).

## Scale model

This compact row is intended to remain usable when the Registry grows from four entries to an entire county. Individual facility pages hold the subarea matrix, qualifications, field-check queue, sweep, and evidence links. The county index should stay scannable.
