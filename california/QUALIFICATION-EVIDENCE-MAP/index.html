    How to read this map¶

    These are provisional qualification statuses based on the research already in the repository. They answer whether the present corpus is sufficient for the matrix row—not whether the law is favorable to an auditor.

    • Supported means the existing corpus contains enough authority/research to run the ordinary branch responsibly, subject to recorded local facts and limitations.
    • Researched-Unresolved means the project has meaningfully researched the issue but preserves a genuine unresolved boundary rather than inventing a categorical answer.
    • Gap means the present research record is not sufficient for an activation-grade branch.
    • Not Applicable would require a documented legal reason; none is assigned in this population pass.

    A Gap count is not a project-completeness percentage. Multiple rows can point to the same missing doctrinal slice. The activation backlog therefore uses deduplicated work packages below.

    Re-evaluation rule¶

    When a Gap package is researched, update the affected rows individually. Preserve Researched-Unresolved when a systematic search demonstrates that the controlling answer is genuinely unsettled; do not convert uncertainty to Supported merely to reduce the Gap count.

    If new research exposes a missing national recurring scenario rather than a California-specific hole, update the national scaffold first and then re-run the affected California rows.
